# Portfolio Pro

React + Vite portfolio: animated hero, smart nav-bar, dark/light mode.

## Run
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in /dist

## Edit
- src/data.js   → ALL your content (name, roles, projects, skills, links)
- src/styles.css → colours (top of file) and layout
- public/       → resume.pdf, your photo, favicon
